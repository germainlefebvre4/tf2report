# Introduction

![Status: Completed](https://img.shields.io/badge/status-Completed-brightgreen)

This plan captures the implementation of Terraform plan JSON parsing and data structure definitions.

## 1. Requirements & Constraints

- **REQ-001**: Parse Terraform plan JSON generated by `terraform show -json`.
- **REQ-002**: Map plan structure to Go types for resource changes and outputs.
- **CON-001**: Use standard library JSON decoding.
- **GUD-001**: Keep parsing errors contextual and user-friendly.

## 2. Implementation Steps

### Implementation Phase 1

- GOAL-001: Implement Terraform plan parsing and core data structures.

| Task | Description | Completed | Date |
|------|-------------|-----------|------|
| TASK-001 | Define `Plan` struct with format version, Terraform version, resource changes, output changes | Yes | 2026-01-02 |
| TASK-002 | Define `ResourceChange` struct with address, type, provider, change details | Yes | 2026-01-02 |
| TASK-003 | Define `Change` struct with actions and before/after states | Yes | 2026-01-02 |
| TASK-004 | Implement `ActionType` constants and `GetPrimaryAction()` logic | Yes | 2026-01-02 |
| TASK-005 | Implement `Parser` with `ParseFile()` and `Parse()` methods | Yes | 2026-01-02 |

## 3. Alternatives

- **ALT-001**: Use a streaming decoder for large plans. Deferred until needed.
- **ALT-002**: Use third-party Terraform SDK types. Rejected to keep dependencies minimal.

## 4. Dependencies

- **DEP-001**: Go standard library `encoding/json`.

## 5. Files

- **FILE-001**: [pkg/terraform/types.go](pkg/terraform/types.go) - Plan and change types.
- **FILE-002**: [pkg/terraform/parser.go](pkg/terraform/parser.go) - JSON parsing logic.

## 6. Testing

- **TEST-001**: Parse valid plan JSON file.
- **TEST-002**: Parse invalid JSON and verify error handling.

## 7. Risks & Assumptions

- **RISK-001**: Terraform JSON schema changes could break parsing.
- **ASSUMPTION-001**: Input plans match Terraform JSON format version in use.
